# RoboRoute-FMS (Autonomous Fleet Orchestrator)

RoboRoute-FMS is a containerized, production-grade **Fleet Management System (FMS)** designed to orchestrate, coordinate, and monitor autonomous mobile robots (AMRs) in real time. 

The system leverages an event-driven architecture to decouple real-time robot telemetry data streams from transactional processing layers. This project directly simulates the backend software framework required to manage multiple automated guided vehicles operating on live warehouse floors.

---

## 🛠️ System Architecture & Technology Stack

The infrastructure is fully containerized and runs on an isolated network bridge to handle high-frequency data ingestion loops smoothly.
